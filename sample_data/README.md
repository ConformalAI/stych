# Sample data

Small, fully synthetic datasets for trying Stych. They were written for this project and contain no real people, companies, or transactions. They are covered by the repository's license.

| File | Use it to try |
|---|---|
| `cafe_sales_dirty.csv` | Cleaning: `ERROR` / `UNKNOWN` placeholders, blanks, a duplicate row, charts and aggregations |
| `customers_sample.csv` | Duplicate detection and fuzzy matching (near-duplicate names such as Alice/Alicia Morgan), filters, linking |

Please do not add data you did not create or do not have clear rights to redistribute. Do not add real customer or business data.
